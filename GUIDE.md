# Experimental Guide

## 1. Overview
This guide provides instructions for reproducing the experiments in our study.

## 2. Dataset
Please download our prepared dataset from the Google Drive link: [https://drive.google.com/drive/folders/1TBcJnfzfeKUPOWmiy-81_fxWWm4IXH_T?usp=sharing]
The dataset contains 306 images of books, remote controls and spoons under different occlusion conditions.

## 3. Running the experiments
- Download the dataset.
- Copy the source code from the detectors folder.
- Install Python and the required libraries listed in requirements.txt.
- Run the code in a Python-compatible environment.
- Run the provided scripts to test the pretrained models on the dataset.
- To reproduce the experiment at a confidence threshold of 0.1, change the confidence threshold from 0.4 to 0.1.
- Record the results.

## 4. Reproducing the results
The raw detection results are provided in the results folder for reference and comparison.
